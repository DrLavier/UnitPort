UnitPort Layered IR - Frontend UI Integration Checklist
Target audience: frontend codex agent(s)
Date: 2026-02-16

Goal
- Build UI panels and node editors against stable layered IR contracts.
- Do not depend on backend internals outside `system.ir` exports.

Canonical imports
- from system.ir import WorkflowIR
- from system.ir import LayeredIRBundle
- from system.ir import MissionIR, BehaviorIR, CommandIR
- from system.ir import SafetyIR, ObservabilityIR, ExecutionIR
- from system.ir import SubgraphIR, SubgraphPort
- from system.ir import DefaultLayeredIRBridge, DefaultLayeredIRSerializer

Required top-level UI sections
1) Mission Section
- Maps to: MissionIR
- Required fields:
  - entry_node_id (string)
  - exit_policy (enum-like string: complete_all/first_success/fail_fast)
  - metadata (key-value map)

2) Behavior Section (fine-control editor)
- Maps to: BehaviorIR
- Required fields:
  - initial_state (string)
  - terminal_states (string list)
  - states (string list)
  - transitions (list of BehaviorStateTransition)
    - from_state, to_state, guard, action_ref
  - motion_params (list of MotionParamSpec)
    - name, value, unit, min_value, max_value, tunable_realtime
  - sensor_bindings (list of SensorBinding)
    - channel, event_type, sample_rate_hz, filter_ref
  - custom_logic_refs (string list)

3) Command Section
- Maps to: list[CommandIR]
- Required fields per command:
  - command_id
  - command_type
  - payload (json object)
  - timeout_sec
  - retry_max_attempts
  - preemption_policy

4) Safety Section
- Maps to: SafetyIR
- Required fields:
  - limits (json object)
  - guards (json object)
  - estop (json object)

5) Observability Section
- Maps to: ObservabilityIR
- Required fields:
  - event_channels (string list)
  - metrics_interval_hz (number)
  - audit_enabled (bool)

6) Execution Section
- Maps to: ExecutionIR
- Required fields:
  - scheduler_mode
  - cancel_grace_period_sec
  - failure_strategy
  - concurrency_policy

7) Subgraph Packaging Section (ComfyUI-style)
- Maps to: list[SubgraphIR]
- Required fields:
  - subgraph_id
  - display_name
  - version
  - inputs (list[SubgraphPort])
  - outputs (list[SubgraphPort])
  - internal_node_ids (string list)
  - metadata (json object)
- Required fields for each SubgraphPort:
  - name
  - direction (input/output)
  - data_type
  - required
  - default

Minimal backend coupling rules
- Frontend should treat `LayeredIRBundle` as editable document state.
- Serialize via `DefaultLayeredIRSerializer.to_dict`.
- Keep unknown fields pass-through when possible.
- Do not assume bridge methods provide completed logic in v0.1.

Basic UI actions to implement
1) Create default bundle
- bundle = LayeredIRBundle()

2) Edit and validate client-side shape
- Ensure required keys exist before submit.

3) Bind to WorkflowIR
- bridge = DefaultLayeredIRBridge()
- workflow_ir = bridge.apply_to_workflow_ir(workflow_ir, bundle)

4) Export
- serializer = DefaultLayeredIRSerializer()
- payload = serializer.to_dict(bundle)

ComfyUI-style packing actions (v0.1 contract level)
1) User selects workflow nodes.
2) UI creates SubgraphIR:
- internal_node_ids = selected node IDs
- inputs/outputs inferred from boundary edges
3) UI stores SubgraphIR in bundle.subgraphs.
4) UI replaces selection with packaged node view using SubgraphIR.display_name.

Known current limitations (must show in UI as "preview/beta")
- Typed reconstruction (`from_dict`) is currently stub-safe and returns defaults.
- Bridge extraction from WorkflowIR is currently placeholder.
- Runtime consumption of layered contracts is not complete yet.

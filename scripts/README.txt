UnitPort - scripts/ README
==========================

All scripts in this directory are for MAINTAINER / CI USE ONLY.
End users should only need: install.bat and start.bat (project root).

Build pipeline (run in order):
-------------------------------
1. build_runtime.bat
   Downloads Python 3.11.9 embeddable + CycloneDDS 0.10.2 prebuilt.
   Output: runtime/python/, runtime/cyclonedds/, runtime/env/manifest.json

2. build_wheels.bat
   Pre-downloads all Python package wheels for offline installation.
   Output: runtime/wheels/*.whl, updates runtime/env/manifest.json

3. verify_runtime.py
   Verifies the assembled runtime is complete and functional.
   Usage: runtime\python\python.exe scripts\verify_runtime.py
   Options: --json (machine-readable), --category <name>

Distribution:
-------------
4. package_distribution.bat [--zip] [--version X.Y.Z]
   Assembles the folder distribution package in dist_package\.
   Excludes .git, .venv311, __pycache__, runtime/_downloads, etc.
   Pass --zip to also create a .zip archive.

Validation:
-----------
5. clean_install_test.bat
   Simulates a clean-machine install in the current shell.
   Strips global Python/CycloneDDS env vars, runs install.bat + verify.
   Use before packaging to confirm the runtime is self-contained.

Phase 4 (EXE installer — not yet implemented):
-----------------------------------------------
  package_installer.ps1  (planned)
  Wraps the folder distribution into a Windows .exe installer (NSIS/Inno Setup).

Notes:
------
- runtime/python/ and runtime/cyclonedds/ are NOT committed to git.
  They must be generated by build_runtime.bat on each build machine.
- runtime/wheels/ contents are NOT committed to git.
  They are generated by build_wheels.bat.
- runtime/env/manifest.json IS committed (empty template).
  build_runtime.bat overwrites it with real version data.
